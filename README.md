# E-MIRROR-PLAY

E-MIRROR-PLAY is the core codebase for Mirror Play, a voice-first emotional intelligence and communication practice platform.

## What this is
Mirror Play helps users practice difficult conversations, improve tone and delivery, and build emotional awareness using AI-powered roleplay, voice analysis, and real-time feedback.

This repository represents the official emerging implementation.

## Core Features (in progress)
- Voice-based interaction (speech-to-text + text-to-speech)
- AI-guided roleplay and rehearsal scenarios
- Emotional tone and communication feedback
- Modular architecture for future expansion

## Tech Stack
- Frontend: React + Vite
- Backend: Node / Express
- Database: Supabase (PostgreSQL)
- AI: OpenAI + ElevenLabs

## Status
Active development. Early-stage foundation.
